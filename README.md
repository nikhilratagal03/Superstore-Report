# Superstore Sales & Profit Analysis – Power BI

## Project Overview
This project is an interactive Power BI dashboard built using the Superstore dataset.
It analyzes Sales, Profit, and Quantity across regions, categories, segments, and time.
The dashboard helps identify business performance trends and key profit drivers.

## Dashboard Screenshot
![Superstore Dashboard](Screenshot%202026-01-07%20095726.png)

## Objectives
- Analyze total sales, profit, and quantity
- Track profit trends by year and quarter
- Compare performance by region and segment
- Identify top and low performing categories and sub-categories
- Enable state-wise filtering for detailed insights

## Tools & Technologies
- Power BI Desktop
- DAX (Data Analysis Expressions)
- Superstore Sample Dataset

## Dashboard Features
- KPIs:
  - Total Sales
  - Total Profit
  - Total Quantity

- Visualizations:
  - Profit by Year and Quarter (Line Chart)
  - Profit by Region (Donut Chart)
  - Profit by Segment (Donut Chart)
  - Profit by Category (Donut Chart)
  - Profit by Sub-Category (Bar Chart)
  - State-wise Profit and Sales Matrix

- Interactivity:
  - State slicer
  - Cross-filtering across visuals
  - Drill-down analysis

## Key Insights
- West region contributes the highest profit
- Technology is the most profitable category
- Consumer segment leads in profit contribution
- Some sub-categories like Bookcases and Supplies incur losses
- Profit varies across quarters, showing seasonal trends

## Dataset Information
- Source: Superstore Sample Dataset
- Data includes:
  - Order details
  - Customer segments
  - Regions and states
  - Categories and sub-categories
  - Sales, profit, and quantity

## How to Use
1. Download the Power BI (.pbix) file from this repository
2. Open it using Power BI Desktop
3. Use slicers and visuals to explore insights
4. Modify or extend visuals as required
